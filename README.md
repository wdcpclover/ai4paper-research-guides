# AI4Paper Research Guides

AI4Paper 团队整理的论文阅读、文献管理与综述准备指南。

这些资料是方法,不绑定任何软件:用纸笔、表格或你习惯的工具都能照做。我们是 [AI4Paper](https://ai4paper.pro/) 团队,文末会说明我们的利益关系。

## 从你要完成的任务开始

| 你现在的任务 | 读这篇 |
|---|---|
| 读一篇论文,想读懂并能回查出处 | [读论文并核对:五个问题与回查方法](docs/read-and-check-a-paper.md) |
| 读了很多篇,想比较并准备综述 | [综述证据表:从逐篇摘要到横向比较](docs/literature-evidence-table.md) |
| 想直接拿空白表格开始 | [证据表模板](templates/evidence-table.md) |
| 想让 AI 助手按这套方法帮你填表 | [文献证据表技能](skills/literature-evidence-table/SKILL.md) |

## 使用原则

- 工具可以帮你整理,**结论与判断仍需你回到原文核对**。
- 每篇指南都写明:适用范围、操作步骤、预期产物、核对方法。
- 示例若使用模拟材料会明确标注,不当作真实论文证据。
