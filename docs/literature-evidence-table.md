# 综述证据表:从逐篇摘要到横向比较

**适用范围:** 你已读过几篇到几十篇相关论文,准备写综述或文献回顾。
**预期产物:** 一张可回查的证据表,以及一份按观点而不是按文献组织的综述提纲。

## 为什么用表,而不是逐篇写摘要

逐篇复述摘要只能得到「这篇说了什么」。综述需要的是「这些研究合起来说明什么、哪里有分歧、还缺什么」。证据表把每篇论文放进同一组维度里,才能横向比较。

## 表头

使用 [证据表模板](../templates/evidence-table.md) 的八列:

| 列 | 写什么 |
|---|---|
| 文献题名与稳定链接 | 题名加 DOI 或可长期访问的链接 |
| 研究问题 | 作者回答的问题,一句话 |
| 样本或材料 | 谁、多少、从哪里来 |
| 方法 | 做法与关键变量定义 |
| 主要发现 | 作者明确报告的结果 |
| 局限 | 作者承认的与你判断的 |
| 原文位置 | 页码、段落或表格编号 |
| 可支持的论点 | 这篇能支撑你综述里的哪一句话 |

## 操作步骤

1. **定问题。** 先写下你的综述要回答的问题,没有问题的表只是资料堆。
2. **逐篇填表。** 每填一格都回原文确认;读不到的写「待核查」。
3. **横向比较。** 看三件事:这几篇在回答同一个问题吗?结果差异来自材料、方法还是情境?哪些观点互相支持,哪些有分歧?
4. **按观点分组。** 把支持同一论点的几行放在一起,每个论点写一句话和对应的原文位置。
5. **搭提纲。** 每个论点是一节:先给你的判断,再列证据,再写分歧与局限。
6. **标出缺口。** 没有文献支持的论点,要么补读,要么删掉。

## 核对方法

- 每个「主要发现」都应该能在「原文位置」找到;抽查 3 到 5 行,从表格翻回原文。
- 综述中的每个数字和结论,都能追溯到表里的某一行。
- 不要让工具替你生成「看起来合理」的格子。工具可以帮你整理,论证和判断需要你来完成。

## 常见问题

- **表填不满怎么办?** 空着并写「待核查」,比编一个答案好。
- **文献太多填不过来?** 先挑最相关的 10 到 15 篇建立框架,其余再补。
