# 读论文并核对:五个问题与回查方法

**适用范围:** 你正在读一篇论文,希望读完能用自己的话讲清它,并且写作时能快速回到原文。
**预期产物:** 一张论文小卡片(五个问题的答案,每条带原文位置)。
**所需时间:** 一篇约 30 到 60 分钟,视难度而定。

## 先回答这五个问题

读完摘要、引言和方法后,逐条写下答案,并记录对应的页码或段落:

1. **作者想回答什么问题?** 用一句话写,避免照抄摘要。
2. **用了什么材料或数据?** 样本是谁、有多大、从哪里来。
3. **用什么方法得出结论?** 实验、问卷、模型还是文献梳理;关键变量怎么定义。
4. **主要发现是什么?** 只写作者明确报告的结果,并注明出自哪张表或哪一节。
5. **在什么条件下成立?** 作者自己写的局限,加上你认为样本与方法带来的限制。

## 回查方法

- 每条答案后面写原文位置,例如「第 4 页第 2 段」「表 3」。
- 遇到术语或统计结果读不懂,先回到作者的定义和方法部分,不要只看摘要。
- 翻译或解释顺畅不等于理解准确。涉及研究设计、变量定义和统计结果的句子,一律回原文核对。
- 引用别人的结论时,区分「作者的发现」和「作者对前人研究的转述」。

## 自检

读完后合上论文,用自己的话向别人讲 3 分钟:问题、做法、发现、局限。讲不清的地方,就是还没读懂的地方。
