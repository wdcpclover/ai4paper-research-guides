# 文献证据表

用于帮助用户把已提供的论文材料整理成综述证据表。目标是「可回查」,不是「看起来完整」。

## 输入

用户提供的论文全文、摘录或笔记,以及用户自己的研究问题。没有研究问题时,先请用户写一句话。

## 输出

按 `templates/evidence-table.md` 的八列输出一张表:文献题名与稳定链接、研究问题、样本或材料、方法、主要发现、局限、原文位置、可支持的论点。

## 规则

1. **只用用户提供的材料。** 材料里没有的信息,对应格子写「待核查」,不要用常识或记忆补齐。
2. **每个「主要发现」必须带原文位置**(页码、段落或表格编号)。给不出位置的,改写为「待核查」。
3. **区分作者的发现与作者转述的前人研究。** 只记录前者。
4. **局限分两类标注:** 作者自己写明的,以及根据样本或方法可推断的(后者要写明是推断)。
5. **不替用户下结论。** 「可支持的论点」写成候选,最后由用户判断。
6. 填完后列出所有「待核查」的格子,提醒用户回原文确认。

## 完成后

提示用户:抽查几行,从表格翻回原文核对;结论与判断仍由用户负责。
